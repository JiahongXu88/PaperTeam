## 1. 两层指标体系（跨臂公平性的核心设计）

| 层 | 定义 | 采集者 | 作用 |
| --- | --- | --- | --- |
| **E 层（External，主指标）** | 评估方对三臂**最终产物**统一重算的指标 | 外部统一核验器（离线，M10.1 实现，机械规则复用 PaperTeam 已有纯函数口径避免另造轮子） | 三臂可比，进主结论 |
| **I 层（Internal，遥测）** | 各系统运行期自记录的指标（仅 P 有完整落盘） | 从 `PROJECTS_ROOT/{projectId}/` 离线收割（AUDIT §3.7 路径清单） | 只描述 P 臂过程质量，**不与基线直接对比**（基线无对应物） |

原则：LLM-judge 类指标只允许做**预筛**（缩小人工核验范围），且必须与人工标注对齐
校准（复用 `evaluation/calibration/` 通道，M6.8 已有 agreement rate 计算）；机械可判
的（DOI 解析、逐字匹配、结构存在）一律机械。

## 3. 关键口径细则（易错点固定下来）

### 3.1 A3/A4 身份匹配

`match(引用, gold) := DOI 相等 ∨ (arXivId 相等) ∨ (归一化 title 相等 ∧ 年份差 ≤1)`。
归一化复用 `citation/bibliography.ts` 的 identityKey 思路（小写/去标点/去冠词）。
gold 冻结后任何匹配规则改动须重跑全部三臂（规则进实验 manifest 记版本）。

### 3.2 B1/B2 分母与 OA 子集口径

- **论断抽取**：终稿中每个「含 `\cite` 且含可检验断言（数值/比较/存在性陈述）」的
  句子为一条可检验论断；抽取规则机械（正则）+ 抽样人工复核抽取质量（每篇 10 句）。
- **支撑判定**：取被引文献全文（OA 子集）→ 先机械逐字匹配（复用
  `evidence/quoteVerification.ts` 的 NFKC 归一化口径）→ 命中即 verbatim-supported；
  未命中进入人工/LLM 预筛语义判定（supported-paraphrase / unsupported / unrelated）。
- **双口径强制**：`B1-OA`（分母=被引文献可获取 OA 全文的论断）为主口径；
  `B1-all`（分母=全部论断，取不到全文记 unverifiable 单列）为副口径。**理由**：
  三臂引用的 OA 可得率不同（P 臂偏 OA 全文），单用 all 口径会把「引得好但付费墙」
  误判为无支撑。
- B2 = unsupported / (supported + unsupported)（把 unverifiable 从分母剔除的严格版）
  与 unsupported / all（宽松版）都记录，主口径取严格版。

### 3.3 C2 捏造判定的机械边界

「张冠李戴」（DOI 真但内容引用点错误）不可纯机械判——机械层只做存在性/元数据；
语义错配进 B1 的支撑判定。C2 主口径 = 存在性失败（解析不到该文献）+ 条目悬空
（\cite key 无 bib 条目）。

### 3.4 E3 修订探针的公平性

探针指令（如「请压缩 Related Work 并保留全部技术论断」）对所有臂在同一时点注入
（拿到 v1 产物后），同规则限时。L 臂在会话内续写、C 臂继续同一 session、P 臂走
existing_paper_improvement 旁路或 review→revision 触发（实现选型归 M10.1，协议只锁
「同一指令文本、同一时限、无额外提示」）。

## 5. F 组（成本）逐臂采集法（对冲审计 G1/G3）

| 臂 | F1 tokens | F3 money | 备注 |
| --- | --- | --- | --- |
| P | 驱动器轮询 `GET /api/runtime/status` 差分（liveExp1 先例）+ stdout `[pi-runtime] usage` 行解析兜底（M9.7.1 先例），run 前后各拍快照 | 差分得到的 estimatedCost；或 F1×价目 | 不可重启后补采——采集器随 run 在线（协议 §4） |
| C | `claude -p --output-format stream-json --verbose` 转录中的 usage 事件（input/output/cacheRead/Write tokens 逐消息累计） | F1×价目表（同一网关 GLM-5.3 价目；Claude 系模型用官方价目） | 转录 JSONL 全量存档（兼作过程分析） |
| L | API 响应 usage 字段累计 | 同上 | 最简单 |

价目表随实验 manifest 冻结（版本+日期）；拿不到当期网关价目 → F3=null 只报 tokens。
**money 永不事后换算口径混用**。

## 6. 明确不设计的指标（不可采集/不诚实）

| 常见诱惑 | 排除理由 |
| --- | --- |
| 「绝对新颖性分数」 | 无 ground truth；盲评 novelty 维只做相对评级 |
| 过程级 Agent 行为质量（工具选择是否聪明） | P 臂转录不落盘（G11）、C 臂转录格式异构；只做描述性附录 |
| P 臂 vs 基线的「内部 gate 通过率」对比 | 基线无 gate，不可比；gate 是 P 的机制而非质量证明 |
| 自动化「写作质量分」（LLM 单判） | 无信度证据；写作质量只认人工盲评（+校准过的预筛） |
| 跨臂「检索 recall」（对全库） | 全库无界；只对冻结 gold 算 A3 |

## 7. 统计分析计划（预注册）

1. **配对单位**：task × rep。主对比 P vs C（核心问题）；P vs L / C vs L 作阶梯参照。
2. **主终点（4 个）**：C1（引用存在率）、B1-OA（接地率）、B2-严格（无支撑率）、
   D3（专家总评）。次要：A3、D1、E3、F1/F2/F3。
3. **检验**：Wilcoxon signed-rank（同卡配对）；n=6-8 时只报：中位数差、效应量
   （r = Z/√n）+ bootstrap 95% CI（10k 重采样）+ 方向一致性（赢的任务比例）。
   p 值照报但**不作为主要声称依据**（样本量诚实）。
4. **多重比较**：4 主终点 Holm 校正；次要指标明示探索性。
5. **预注册失效条件**：若 pilot 显示某主终点方差近零（天花板/地板效应，如 C1 三臂
   均 ≥0.98），该终点降级为描述性，不进显著性声称——在 pilot 报告中登记后再跑 main。
6. **异常处理**：run 失败（系统错误）→ 按协议重试 1 次，仍失败则该 (task,rep,arm)
   记 DNF 并在分析中作缺省配对剔除（同时报告 DNF 率本身——它也是可靠性指标）。

## 8. 指标→产物 schema（实现契约，M10.1 物化）

每 run 产出一份 `run-record.json`（进 `evaluation/reports/m10/`）：

```jsonc
{
  "runId": "m10-<task>-<arm>-<rep>",
  "task": { "taskId": "…", "sha256": "…" },
  "arm": "L|C|P", "model": { "spec": "…", "channel": "…" },
  "artifacts": { "tex": "…sha256", "bib": "…sha256", "pdf": "…sha256|null" },
  "metrics": { "A1": 23, "A3": 0.62, "B1_OA": 0.71, "…": "…" },
  "cost": { "inputTokens": 0, "outputTokens": 0, "wallClockMin": 0, "moneyUsd": "null|number" },
  "telemetry": { "…": "仅 P 臂，§4 全量" },
  "interventions": [ { "at": "…", "kind": "hitl|continue", "detail": "…" } ],
  "status": "completed|timeout|dnf|partial"
}
```

JSON 为事实源、Markdown 摘要随行——沿用 `evaluation/reports/` 既有纪律。
