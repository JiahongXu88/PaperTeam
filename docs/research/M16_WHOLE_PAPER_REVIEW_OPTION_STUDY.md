## 1. 三个臂

| 臂 | 是什么 | 产品位置 |
|---|---|---|
| A / S@10 | 一次调用读全文，出 10 条意见（上一轮同一 prompt） | 评测基线，不进产品 |
| B | 当前生产：长文档单元审稿 + 跨章一致性（`review.run` units 模式） | 产品现状 |
| C | B + 单元与跨章之后**一次**整稿综合调用（`ReviewerService.reviewWholePaper`，≤ 8 条） | 本轮新增，`PAPERTEAM_REVIEW_WHOLE_PAPER` |

C 的工程约束（`backend/test/workflow/wholePaperSynthesis.test.ts` 5 例）：
- 关闭时单元 prompt 与开启时逐字节相同，不发整稿调用；B 与 C 共用同一次运行（配对设计），B 的结果不受 C 影响。
- 输入为被审全文（FULL_TEXT）；超过 `PAPERTEAM_REVIEW_WHOLE_PAPER_MAX_CHARS`（160000）时退化为各章摘要并标 GLOBAL_DIGEST——不冒充通读全文。新集 10/10 次执行均为 FULL_TEXT。
- 只报研究问题 / 贡献 / 强基线 / 实验充分性 / 论证闭环类意见；产出恒为 `origin: whole_paper_synthesis`、`blocking=false`、`AUTHOR_CHECK_REQUIRED`（L2 待核验），**永不进 L1**；不计入正文覆盖率（整稿节点不能掩盖未读章节）。
- 调用失败如实记 `coverage.wholePaper.status = failed`，单元结果与覆盖率不变。
- 不接触专家参考：整稿 prompt 只含被审正文；参考意见只在裁判阶段出现。

### 参考外独立核验（盲化）

judge2 之后，每篇每臂取前 3 条「未与人类意见对齐、可定位」的条目，去掉臂 / 名次 / 严重度，共 83 条；由一个只看论文正文与盲化池的独立执行者写确定性规格（不读 key / 裁判 / 生产目录 / 人类意见），脚本对原文计算结论。

| 臂 | 条数 | INDEPENDENTLY_VERIFIED | REFUTED | UNVERIFIED（前提可引、结论需判断） | NOT_EVALUATED |
|---|---|---|---|---|---|
| S | 17 | 1 | 0 | 8 | 8 |
| B | 36 | 4 | 0 | 29 | 3 |
| SYNTH | 30 | 2 | 0 | 27 | 1 |

- SYNTH 的 2 条：2IhkyiF3to 正文写 VGG19/CIFAR100 在「Figure 2 b)」而图注把它标为 e)；7HEMpBTb3R 全文无任何方差 / 误差棒 / 重复运行 / 显著性（排除了同名超像素算法 SEEDS），作者据 0.5–1.5 点差异下结论。
- 规格执行者记录的「前提与原文不符」：S、B、SYNTH 各 1 条（V011、V014、V059），均记为 NOT_EVALUATED 而非 REFUTED（脚本只有确定性反证才记 REFUTED）。另有若干条事实小错（如重复行写成 Entity-13 实为 Entity-30、称未报告不确定性而论文有 bootstrap CI），都落在 UNVERIFIED 内。所以「0 REFUTED」只说明没有确定性反证，不说明误报率为 0；三臂之间没有看到 SYNTH 更差的信号。
- 局限：规格执行者与被测模型同族、看过开发集；每臂每篇 ≤ 3 条是下限不是全量。

## 5. 运行中暴露的问题（未改代码，如实记录）

1. **整稿调用被单次运行上限饿死（2/12 篇）。** M8OGl34Pmg、YiyG1tHDxq 的单元审稿输出漂移成中文，缺 claims 字段 → 9 / 7 次论断契约修复调用 → 本协议设定的 21 次运行上限用尽，跨章与整稿调用被拒（YiyG1tHDxq 还有 1 个单元未审，覆盖 17/18，Gate 如实不完整）。主判定把这两篇记 C = B（对 hybrid 不利）。产品缺省没有 21 次这样紧的单篇上限，但整稿调用排在最后，任何预算紧的部署里它最先被牺牲——这是已知取舍。
2. 语言漂移 → 修复调用放大是既有缺陷（上一轮每篇约 1 个中文单元，0–2 次修复），本轮未改单元 prompt，原因未查明。

## 6. 决定

- 执行：`backend/src/config/config.ts` 缺省 `wholePaperSynthesis = on`，`PAPERTEAM_REVIEW_WHOLE_PAPER=off` 回滚；`.env.example` 说明；配置缺省测试。整稿条目仍恒为 L2、不阻断、不计覆盖率，L0–L4 规则与阈值不变。
- 没有做、也不主张：用 S 替代 B（B 有逐单元覆盖、论断账本、确定性核验与 Gate 证据链，S 没有）；扩大 SYNTH 条数；在这 12 篇上再调 prompt。
