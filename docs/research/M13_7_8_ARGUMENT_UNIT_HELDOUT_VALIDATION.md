## 9. 方法学限制与本轮偏离

- **不是完整三因素消融**：没有 H3-only 臂，B − C、B − D 不能解释为 H3 的独立因果贡献，交互作用不可分离（protocol.json `designLimits`）。
- **单样本、单次采样**：GLM 输出不确定，A/B/C/D 各一份；"B 高于 A 4 个百分点"与"C 低于 A 8 个百分点"都在单次采样噪声可及范围内，本报告只做方向性结论。
- **D 的长度分配与 B 相同**（180 / 400 / 400 / 320 / 160），因此 D 同时带有"上限语义"与"按角色重分配长度"两层改动；共享的一句 `长度口径` 必然点名"不为凑字重述 / 重复限制 / 补写细节"，这在 A、C 中不存在。
- **偏离 protocol 字面**：protocol 写"C、D 只在第一阶段过门才跑"。第一阶段 B 未过探测器门，但人工阅读显示它不是质量上的明显失败（清单全保、无事实违规、更便宜），任务要求"若不成立要指明是证据分配、篇幅还是任务的问题"，而这只能靠 C、D 回答；因此在预算内（20 任务，无追加）继续跑了两臂。这里如实记录，不把它写成"过门后的消融"。
- **探测器缺陷在 LIVE 后修复**：门禁数字保留冻结口径，修复口径只作次要报告，两者排序一致；没有改标记、阈值或输入去改善任何一臂。标记有两处已知漏检（"本文无实验"的窗口 16 字不够长；`no_ranking` 受 `\%` 缺陷影响），按纪律未加宽，用人工计数替代（§4、§5）。
- **人工分类有判断成分**：X（维度提醒）与 M（完整再述）的边界、E（结论枚举）是否有害，均按同一规则施于四臂并给出句号，可复核但不是双盲多人打分。

## 10. 是否进入生产

**本轮不进入。** 依据：（1）预注册的首要指标未通过，且修复探测器后仍未通过；（2）B 的新症状——路标模板句与比较节逐字回引——是方案文本直接诱导的（任务块多次使用"见「X」一节"句式，模型照抄成正文），需要先改方案再验证，而不是边上线边修；（3）单样本。

若后续继续，建议顺序（都不在本轮执行）：

1. 把任务块里的"见「X」一节"从指令措辞改为约束（例如"全文最多一句指向其他节的路标，禁止在节首 / 节尾写'将在 / 已在某节展开'"），比较节改为"只写对照结论，不复制机制句"；然后在**同一 held-out 夹具**上重跑 B 一次，并补 H3-only 臂（全量证据 + 原长度 + 任务块），预算 10 任务。
2. 同时多 seed（≥ 3）跑 A 与 B，给出占比差的区间，再决定是否值得改 `writingSectionsStage`。
3. 生产改造方案（仅方案）：`writingSectionsStage` 逐节 `selectForWriting`（按 Outline 的 `evidenceIds` 或按节 keyPoints 检索），Outline 可选字段 `role` / `task` / `doNotExplain` / `targetLengthUpperBound`，`buildSectionPrompt` 的 `目标长度` 行区分"约"与"不超过"；大纲期信息预算 warning（唯一 quote 字符 vs 要求长度）。风险：Planner 生成 `doNotExplain` 的可靠性（M13.7.4 的 Planner 失败）、路标句的 Reviewer 识别、Fact Preservation 对数值在 owner 节存在的豁免。
4. 独立排期：探测器增加"路标句"分类（只报告不改分数），以及机制句级 quote 覆盖核对（M13.7.7 §8）。

## 11. 对任务十一问的直接回答

1. **主题**：对比 / 非对比视觉自监督表示学习（SimCLR / MoCo / BYOL / SimSiam），与历史样本完全独立，仓库零出现。
