## 12. Known Limitations

1. **Writer 修订的数值删除倾向**：两轮修订均以删除表格行/数值响应审稿
   （review 要求补证据时 Writer 选择删声明），连续触发 Fact Preservation
   拦截并最终阻止 Draft 冻结、烧掉 run；证据池小（2 篇全文）时更明显。
   修订计划虽派发 factRegressions 恢复条目，但 Writer 执行仍偏向删——
   prompt 纪律需「恢复优先于删除」；
2. **run failed 后无引导式恢复**：本例恢复链路（restore → review → gate →
   build）分散在 UI 版本历史 + 手动 API，验收者需理解编排语义才能走通；
3. **PDF 无 hyperref**：引用/参考文献不可点击（编号追溯已验证，点击交互
   缺失）；
4. **manuscript 文件查看器缺失**（M9.5 §14-8 延续）：.tex/references.bib
   核对走磁盘；
5. **artifact 条目 metadata 未核验**（M9.5 §14-3 延续）：canonical 14 条中
   12 条 LLM 回忆条目未 scholarly enrich（本例未进入正文引用，无实际影响）；
6. **sidebar-responsive 既有断言不一致**（非 M9.6 引入，零代码改动下暴露）：
   有项目时 `.sidebar-recent` 实高 ~68px/条 < 断言 `>=150`；M9.5 全绿时该
   用例因栈内无项目被 skip（23 passed + 35 skipped = 58 全量），本次首次
   真实执行暴露。属 M7.0 测试断言与当前 CSS 的不匹配，未修（不属验收范围）；
7. **Playwright 栈配方敏感性**：`workflow.spec「无模型栈」`4 用例需要
   「真实 pi runtime + 无模型」栈（research.idea 走 runtime_unavailable 失败
   路径）；在 scripted 栈下 D 用例必挂（scripted 让调研成功）、在
   scripted+`CITATION_METADATA_ENABLED=0` 栈下 A 用例因 run 秒完（cancel
   按钮合法消失）而挂——BROWSER_ACCEPTANCE §5 的 scripted 配方与该套用例
   的隐含前提不一致，配方适用矩阵需文档化（§13-7）；
8. **writing.sections 无增量重写**（重跑全量重写全部章节）；
9. **工具链观察（非产品）**：playwright-mcp 0.0.82 的 click 参数从 `ref`
   变为 `target` 且 ref 每会话漂移，跨会话复用 ref 必错位——本次改用
   `browser_run_code_unsafe` + role 定位完成全部交互；`PAPERTEAM_RUNTIME_ROOT`
   隔离时凭据需复制到 `<root>/runtime/pi/agent/auth.json`（config 会再拼
   一层 `runtime`，双层 runtime 目录易踩）。

## 13. M10 Recommendation

1. **Writer 数值保护策略**（P0）：修订 prompt 增加硬纪律——删除/改写实验
   数值与表格行必须携带 evidence 授权或修订计划恢复指令，恢复优先于删除；
   可在 `reviseSection` 输入侧做 plan-item 到数值白名单的确定性注入；
2. **run failed 引导式恢复**：build.draft 被 Fact Preservation 阻止时，
   UI 提供一键「恢复至上一合规修订并重新评审构建」（把本次人工走通的
   restore→review→gate→build 链路产品化）；
3. hyperref + 可点击引用/参考文献（含 `sourceId` 追溯跳转）；
4. manuscript .tex / references.bib 文件查看器（M9.5 §14-8）；
5. scholarly enrich artifact 条目（复用 SourceImportService，M9.5 §14-3）；
6. sidebar-responsive 断言与 CSS 对齐（min-height 或断言改内容高度语义）；
7. e2e 栈配方文档化：scripted（UI 冒烟/安全模式）vs 无模型真实 runtime
   （workflow「无模型栈」用例）vs dev 真实模型（模型门控用例）的适用矩阵，
   并给 workflow A 用例去掉对 provider 时速的隐含依赖（如断言改为
   「运行中显示取消，或已完成显示完成态」）；
8. `requireEvidenceBackedCitations` Final 档评估：本轮 coverage 2/2=100%
   （小样本），继续积累数据后决定是否默认开启；
9. （可选）逐节增量写作 / 重写。
