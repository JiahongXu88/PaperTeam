## Metrics (all computed by `evaluate.py`, deterministic)

1. `session_ok` — session completed (not error / budget / turn-limit), cost USD, turns, duration.
2. `verify_exec_ok` — `figure.py` re-executed by the operator in a fresh `verify/` directory (`MPLBACKEND=Agg`,
   timeout 240 s) without error; this is the reproducibility check.
3. `pdf_present`, `pdf_vector` (pymupdf: drawings count > 0 and no embedded raster image unless heatmap), `pdf_pages`,
   `pdf_width_mm` vs target, `fonts_embedded`, `fonts_list`, `cjk_font_embedded` (zh tasks).
4. `text_labels_found` — fraction of expected labels (method names, axis titles, Chinese labels) extractable from the
   PDF text layer; `tofu_risk` = zh labels missing from text layer or `Glyph ... missing` warnings in stderr.
5. `data_fidelity` — the script reads the provided data files (regex on `read_csv|loadtxt|open(`), does not use
   `np.random` for data (jitter allowed only if flagged), uses all rows (checked by instrumenting pandas in verify run:
   row counts of loaded frames equal CSV row counts), no numeric literal duplication of the dataset.
6. `skill_qa_checks` — the skill's own `scripts/check_colors.py`, `check_fontsize.py`, `check_dimensions.py`,
   `check_export.py` run against both arms (skill-defined rubric; reported as such, not as ground truth).
7. `visual_rubric` — operator scoring (1–5) on clarity / labelling / colour / print-readiness / correctness, done on
   PNGs renamed to blinded ids (`dashboard/blind_map.json` is only opened after scoring).

## Honesty rules

- Every model call is recorded (`runs/*/claude_result.json`); the ledger `runs/ledger.json` is the budget source of truth.
- Failures are reported as failures. No re-rolling of a bad session to make an arm look better; replications are
  pre-declared above.
- Arm C is not a model arm; it shows what PaperTeam produces today for the same data, including "not supported".
