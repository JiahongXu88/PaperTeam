> 日期：2026-10-14。基线 `main @ 1f983ff`。语料与来源见 [语料报告](M14_0_1_REAL_THESIS_PAPER_CORPUS.md)；逐案例 Evidence Matrix 原件在 `D:\PaperTeamData\M14_0_1_RealThesisPaperStudy\mappings\case_*.{md,json}`（不入库）。
> 标记：**OBSERVED** = 在至少一个案例中以页码级证据实际观察；**SUPPORTED_INFERENCE** = 有证据但非直接；**DESIGN_PROPOSAL** = 工程建议；**UNKNOWN** = 材料不足。页码为 PDF 页索引。

## 0. 一页结论

1. **核心章 ≈ 小论文的完整再现**（OBSERVED，10/10 正式样本）：中文论文是英文论文的翻译 + 结构重排，表格数值逐位相同（范登平表 5.1 51/52、来斯惟表 3-x 逐位、邓栋表 2.4 逐位、白烨 13 张表全同、宋品皓表 3.1 111/111）；英文论文（控制样本）23% 7-gram 逐字复用、Sanyal 39% 论文正文复用。**篇幅增加来自新增章节与框架文本，不是对原论文的语言扩写。**
2. **成果归属只在全局层面声明**（OBSERVED，10/10）：附录「在学期间成果」列表 + 偶见的研究路线图（白烨图 1.3）；没有一篇在章首写「本章成果发表于…」。章节映射只能靠作者给出或内容匹配推断。
3. **未发表材料普遍存在**（OBSERVED，6/10）：张蒙第 5 章无论文；李谨杰核心论文答辩时仅 "Submitted"，且 ≈37% 页面无论文对应；宋品皓 ≈44 页基于答辩时未发表的预印本；来斯惟第 4 章（20 页）无已发表对应；邓栋 Spark 实验未发表；Sahoo 第 4 章无结果。`thesis_from_papers` **不能只接受已发表论文**。
4. **事实冲突真实存在且集中在少数单元格**（OBSERVED，7/10）：范登平表 4.3 全模型行 0.699/0.630/0.098 vs CVPR Table 5 0.724/0.603/0.092（其余两行相同）；李谨杰表 9 谱归一化损失 1.6288/1.0523/0.6185 vs 论文 1.589/1.022/0.518；宋品皓 YOLOv3 基线 6.57 vs 16.37；白烨 λ 约定反转、基线 11.4→7.6、模型重命名；来斯惟 144 vs 168 组合（删去 GloVe）；Li Qimai 重跑数值 22.0 vs 22.3。**相同实验、不同数值**的根因（重跑、版本、笔误）无法从文档判定。
5. **版本链是常态**（OBSERVED，4/10）：会议版 → 期刊扩展版 → 学位论文（刘磊 PACT→TACO、白烨 Interspeech→TASLP），学位论文跟随期刊版数值但引用会议版为"起源"；一篇论文可拆成两章（刘磊 ISCA、白烨 TASLP21a），两篇可并为一章（张蒙第 3 章、邓栋第 3 章）；章节顺序 ≠ 发表顺序（范登平）。
6. **选择性删减**（OBSERVED，3/10）：白烨删去优于己方的 ESPnet-Conformer 行；来斯惟删去 Paragraph-Vector 基线并静默移除 GloVe；Li Qimai 用 CVPR 方案替换 AAAI 方案。AI 系统**不得**自动做这类删减，只能登记为作者决定。
7. **公开副本会被答辩后修订**（OBSERVED，3/10）：范登平引用 2022 综述、附录填入 2021/2022 卷期；张蒙 2019-06 答辩却列 "Neurocomputing 2020, 397"；Sahoo 成果页在上传前更新。"学位论文"本身是带版本的对象。

| F 已发表论文被排除 | 成果列表中的论文不进正文 | 范登平 ×2、李谨杰 ×2、Sahoo、来斯惟 ×3、Sanyal ×2 |

### 2.2 常见章节组织模式（OBSERVED）

- 结构：第 1 章 绪论（研究背景/国内外现状/研究内容与组织结构）→ 第 2 章 相关工作/预备知识（含符号表：张蒙 1.9、Li Qimai 第 3 章教程）→ 3–4 个核心章（每章 引言/方法/实验/本章小结）→ 总结与展望 → 参考文献 → 在学期间成果 → 致谢/简历。10/10 符合。
- 核心章排序依据研究主线而非发表时间（范登平：数据集 → 模型 → 指标；白烨：三个递进；来斯惟：词 → 文档；邓栋：抽取 → 连接 → 检索）。
- 核心章之间的衔接方式：共享评测工具（来斯惟）、后章组合前章模块（李谨杰第 5 章 = 第 3 + 第 4 章）、统一框架章（Li Qimai 第 3 章、白烨 §3.2 分类）。

### 2.3 可证实的成果继承模式

| 继承对象 | 观察 |
| --- | --- |
| 表格 | 最主要的继承单元；数值逐位相同是常态；重编号（按章）、标题翻译、偶有新增列（范登平表 2.3）或删行（白烨、来斯惟）。 |
| 公式 | 逐条对应（来斯惟 (1)–(10) = (5.9)–(5.17)；李谨杰谱归一化推导；邓栋算法/定理），符号可能统一重命名（Li Qimai）。 |
| 图 | 以相同数据重绘 + 中文标题（范登平图 5.4–5.8）；偶见重复印刷（Li Qimai）；位图继承未在中文样本中直接证实（PDF 解析不区分）。 |
| 实验协议 | 数据集/指标/基线名称继承；基线数值可能被替换（宋品皓 6.57/16.37）。 |
| 文本 | 中文论文：翻译（词面重叠≈0）；英文论文：23–39% 逐字。 |

### 2.4 真实事实冲突类型

1. 同一表格个别行值不同（范登平、李谨杰、宋品皓）——根因不可从文档判定。
2. 约定/符号反转或重命名（白烨 λ；Li Qimai 符号；白烨 LASO-big）。
3. 基线替换或删除（宋品皓、白烨、来斯惟）。
4. 论文版本并存（arXiv v1/v3 为不同稿件；会议 vs 期刊；作者副本 "Revised 2016"）。
5. 元数据漂移：作者名单变动（宋品皓 DMC 一作变更；来斯惟 IEEE IS 版）；成果列表与正式版题名/作者/卷期不一致（Sahoo、张蒙）；参考文献页码矛盾（邓栋）。
6. 公开副本答辩后修订（范登平、张蒙、Sahoo）。

### 2.5 最容易发生不可靠 AI 扩写的位置（SUPPORTED_INFERENCE）

- 绪论/综述章（占 16–31%）：真实论文里这是新写内容且需要大量额外文献；AI 若凭小论文 intro 扩写会产生无来源的"研究现状"。
- 表格新增列/行（范登平表 2.3 的新增 S-measure 列是作者自己的基准运行）：AI 无法补；补了就是造数。
- 无论文章节（参数辨识、仿真、平台、未发表实验）：全部需要作者原始材料。
- 冲突单元格：AI 统一取值 = 覆盖原始成果。
- 「见附录」「supplemental」等翻译残留会被 AI 当成真实的交叉引用。

### 2.6 必须由作者确认的信息（OBSERVED 需求）

哪些论文入/不入学位论文（F 类）；跟随哪个版本（C2）；冲突值取舍或并存声明（C1）；是否删减基线（C3）；未发表章节的材料来源与可写范围（D）；统一符号/术语表（张蒙 1.9）；章节顺序与主线框架；答辩后是否更新成果状态。

### 2.7 系统可以自动完成的工作（SUPPORTED_INFERENCE）

从每篇输入确定性抽取表格单元格、公式、数值、数据集/指标/基线名；跨输入对账同名指标/数据集；检测同表异值并标红；按章投影源文本与冻结事实；生成「在学期间成果」附录与成果来源声明；跨章符号/术语/图表编号一致性扫描；检测翻译残留与悬空交叉引用（"见附录"）；版本注册（arXiv vN / DOI / 作者副本）与变更差异。

### 2.8 系统只能建议、不能执行的工作

论文入选与排除、版本选择、冲突裁决、基线删减、章节主线、新增实验、符号重命名的具体方案、是否把未发表材料写入。

## 3. 与当前 M14 架构假设不一致的证据

| M14.0 假设 | 证据 | 判定 |
| --- | --- | --- |
| 输入 = 已发表小论文（`SourcePaper.publicationStatus` 四值） | 6/10 依赖未发表/在投/答辩后才投稿的材料；吴建军无论文 | 需扩展为通用研究输入（含手稿、实验报告、数据） |
| 一篇论文 ↔ 一个 owner 章 | ISCA/TASLP 一篇拆两章；多篇并一章 | 成果（contribution）而非论文是映射单位，且多对多 |
| 冻结事实 = 小论文中的值 | 学位论文与论文同实验异值（5 例） | 冻结事实需「版本 + 冲突」状态；extracted ≠ verified ≠ confirmed |
| 继承图资产以图片为中心 | 表格（结构化单元格）是最常见继承单元 | 需表格级继承资产 |
| 章节映射可由系统提案后确认 | 真实论文不写章级归属，作者才知道 | 提案必须基于内容匹配并强制作者确认；默认不得自动 confirmed |
| 学位论文篇幅主要靠扩写方法/实验 | 篇幅增量来自新章节与框架；核心章 ≈ 翻译 | Writer 的任务是「新增结构 + 衔接 + 翻译/重排」，不是语言扩写 |
| "thesis" 是单一文档 | 公开副本有答辩后修订；成果状态随时间变 | 学位论文稿与成果列表都需版本/时间戳 |

## 4. 样本限制

见语料报告 §6：作者自存档偏差（高被引 CS 作者）、学科偏向 CS/AI、2014–2023、读到的多为 arXiv 作者稿与修订副本、9+1 组不足以外推。所有比例均为本语料内的描述统计。
