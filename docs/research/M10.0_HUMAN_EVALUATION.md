# M10.0 Human Evaluation Protocol — 盲评设计与评分表

> 日期：2026-09-25 · 里程碑：M10.0 Phase 4（设计文档，**不实现**）
> 输入：[M10.0_EXPERIMENT_PROTOCOL.md](M10.0_EXPERIMENT_PROTOCOL.md)（产物与阶段门）
> 目标：独立专家**盲评**三臂论文，覆盖六个维度：novelty / related work / methodology /
> citation reliability / factual correctness / writing quality。

---

## 1. 评价者

| 项 | 要求 |
| --- | --- |
| 人数 | 每任务 ≥3 名评者（2 名领域相邻 + 1 名方法论/文献工作专家）；全实验共用同一池 |
| 资格 | 具备英文/中文（对应任务语言）文献阅读与综述写作经验（研究生及以上或等效实践）；**与本项目无利害关系**（不知道三个系统各自是哪个、未参与开发） |
| 校准轮 | 正式评前用 1 篇练习稿（历史非实验产物）集体过一遍评分表，统一锚点理解；练习不计数 |
| 负荷 | 每任务每评者：3 篇绝对评分 + 3 对偏好 + 2 篇抽检 ≈ 1.5-2h |
| 报酬/同意 | 按当地标准补偿；知情同意书声明数据仅用于本研究、可随时退出 |

## 2. 盲法设计

1. **匿名化流水线**（评估方执行，评者不可见原始文件名）：
   - 统一重渲染：三臂 `main.tex` 一律套 `neutral-v1` 模板重编译（同字体、同版式、
     同编译链 xelatex+bibtex）；
   - 指纹清除清单（逐项核对入档）：
     - PDF metadata（Producer/Creator/日期统一置空）；
     - LaTeX 源中任何系统自指（`sourceId = {…}` 追溯字段行——渲染前剥离；
       致谢/脚注中的生成声明）；
     - 文件名/目录名（重命名为 `paper-<random3>.pdf`）；
     - 结构习惯（P 臂 8 节固定轮廓）→ 任务卡 `requiredSections` 本就约束三臂同构，
       渲染后逐篇跑一次章节序列比对，序列完全相同则该项风险消除，否则登记；
     - 引用 key 风格（P 臂 `familyYEARword` 确定性 key）→ 渲染前把三臂 bib key
       全部机械重命名为 `ref1…refN`（保序随机重排），\cite 同步映射。
   - 分配：任务内三篇随机编号；**偏好对比与绝对评分的编号不同**（防跨环节记忆）。
2. **评者隔离**：各自独立提交后才开放讨论；分歧裁决只针对分数不针对系统身份。
3. **盲法质检**：每篇评后附 1 题猜测（「你认为这是哪种工具产物？AI对话/通用Agent/
   专用系统/不确定」）。若猜测正确率显著高于 33%（二项检验），判定盲评失效风险，
   如实报告并分析泄漏源（不隐瞒、不废弃数据，标注解读强度）。

## 3. 评价任务结构（每评者 × 每任务）

1. **绝对评分**：3 篇 × 六维 1-5 分（§4 评分表）+ 每维一句理由（必填，防随手打分）；
2. **两两偏好**：3 对（P-C / P-L / C-L 的未知身份版）× 「更喜欢哪篇 + 一句理由」；
   可选 equal；
3. **引用抽检**（citation reliability 的实证分量）：随机 2 篇 × 10 条引用——评者判定：
   该文献是否真实存在（给 DOI/链接检索辅助）+ 被引处陈述是否被该文献支撑（三值：
   支持/部分/不支持）；
4. **事实抽检**：随机 2 篇 × 5 条可检验论断（数值/比较/存在性）——评者检索核验
   （对/错/无法核验）。

抽检样本由评估方机械抽取并预格式化（评者只看论断+引用上下文，不看全文），抽检
结果同时用于校准自动核验器（进 `evaluation/calibration/records.jsonl`，兑现 M6.8
预留的 agreement-rate 通道）。

## 4. 评分表（六维锚定 rubric，1-5）

> 每维独立打分；1/3/5 锚定如下，2/4 为中间档；「不适用」不允许（综述任务六维均适用）。

### D-Novelty 综述增量价值（对领域的洞察贡献）

| 分 | 锚定 |
| --- | --- |
| 5 | 提出非显而易见的综合框架/对比视角/研究空白判断，读后对该领域「怎么走」有新认知 |
| 3 | 有一定的组织与归纳，但视角常规（按时间/按方法罗列），增量有限 |
| 1 | 纯搬运拼贴，无任何综合判断或空白识别 |

### D-RelatedWork 文献工作（覆盖与定位）

| 分 | 锚定 |
| --- | --- |
| 5 | 覆盖该主题应读的核心文献（含近期与经典），脉络梳理准确，对比维度选取有理由 |
| 3 | 覆盖部分核心文献，有明显但非致命的遗漏或归类不当 |
| 1 | 大量应引未引 / 引用与论题错位 / 脉络混乱 |

### D-Methodology 方法与论证（综述方法学严谨性）

| 分 | 锚定 |
| --- | --- |
| 5 | 检索/筛选/综合方法交代清楚可复现，论断-证据-结论链条严密，限定词使用克制准确 |
| 3 | 方法交代笼统但论证大体成立，个别过度概括 |
| 1 | 无方法意识；论断跳跃、以孤例概全、结论超出证据 |

### D-CitationReliability 引用可靠性

| 分 | 锚定 |
| --- | --- |
| 5 | 抽查引用全部真实且确实支撑被引处陈述；引用密度与论断密度匹配 |
| 3 | 少量引用存疑（不影响主干论断）或支撑关系牵强 |
| 1 | 发现捏造引用 / 关键论断无引用支撑 / 大面积引而不当 |

（本维与 §3-3 抽检结果客观关联；评分表允许主观印象，分析时与抽检客观分并报。）

### D-FactualCorrectness 事实正确性

| 分 | 锚定 |
| --- | --- |
| 5 | 抽检事实陈述全部可核验为真；数字、年份、方法归属准确 |
| 3 | 个别可核验错误（次要陈述），无方向性误导 |
| 1 | 关键事实错误 / 方法-贡献张冠李戴 / 虚构实验结果 |

### D-WritingQuality 写作质量

| 分 | 锚定 |
| --- | --- |
| 5 | 结构清晰、段落推进有逻辑、学术语域稳定、可读性强；格式/编译零瑕疵 |
| 3 | 结构完整但行文平/偶有语病或格式问题，不影响理解 |
| 1 | 结构混乱、术语不一致、格式/编译错误影响阅读 |

**总分 D3（METRICS 主终点之一）= 六维等权均值**（分析时同时报六维分量；若某维
信度不达标（§6），从总分剔除该维并登记）。

## 5. 流程与时间线（每任务）

```text
评前包（每评者）：匿名 PDF×3（随机编号A）+ 评分表 + 练习稿已完成的校准记录
  → 绝对评分（独立，限时 60min）
  → 偏好包：匿名 PDF 对×3（随机编号B，与A不同）
  → 偏好判定（限时 20min）
  → 抽检包：预格式化论断/引用卡（20min）
  → 猜测测验 + 人口学元数据（研究领域/经验年限）
提交 → 三评者一致性计算 → 分歧 >1.5 分的维度进入裁决（第4名高级评者盲裁）
```

## 6. 一致性与信度

| 量 | 方法 | 门槛 |
| --- | --- | --- |
| 绝对评分 | Krippendorff's α（ordinal）/ Fleiss κ（序次化后）逐维 | α≥0.4 报告并使用；α<0.4 该维降级为描述性（不进主结论），如实标注 |
| 偏好 | 评者间一致率 + Bradley-Terry 拟合（三臂强度 + 95% CI） | 一致率 ≥60% 方拟 BT；否则只报边际计数 |
| 抽检 | 评者×条目 双录入 20% 重叠样本的吻合率（客观条目应近 100%，否则复核抽检说明） | <90% 时重写抽检说明再重抽 |

## 7. 伦理与数据

- 知情同意 + 可退出；评者身份去标识后仅保留元数据（领域/经验）；
- 原始评分表扫描/CSV 与代码本（codebook：每维定义+锚点）随实验归档；
- 评者不知晓假设方向（H4 预期在评后才可透露）。

| 维度 | 分(1-5) | 一句理由（必填） |
| --- | --- | --- |
| Novelty | ☐ | … |
| RelatedWork | ☐ | … |
| Methodology | ☐ | … |
| CitationReliability | ☐ | … |
| FactualCorrectness | ☐ | … |
| WritingQuality | ☐ | … |

**偏好表**（每对一份）：更喜欢 ☐左 ☐右 ☐难分 · 理由一句。
**抽检表（引用）**：`# | 论断原文 | 所引文献 | 存在? (是/否/查不到) | 支撑? (支持/部分/不支持) | 备注`
**抽检表（事实）**：`# | 事实陈述 | 核验渠道 | 判定 (对/错/无法核验) | 备注`
**猜测测验**：`本篇你认为产自：☐AI对话工具 ☐通用Agent ☐专用学术系统 ☐不确定`

## 9. 与既有资产的衔接

- 抽检-自动核验校准记录直接写 `evaluation/calibration/records.jsonl`
  （schema 兼容：experiment=m10, scenarioId=taskId, arm=匿名编号映射后补）；
- 评者维度命名与 PaperTeam 内部 Reviewer 5 维（问题定义/方法合理性/实验充分性/
  论证逻辑/写作质量）**刻意错开**——人工盲评是外部效度工具，不复用内部评审判据，
  避免循环论证（P 臂的 Reviewer 就是按自己的维度训练的，人工再用同维度会偏向）。
