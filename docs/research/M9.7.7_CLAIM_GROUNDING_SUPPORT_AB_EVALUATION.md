## 1. Goal

M9.7.6 结论：Claim Grounding 机制全链路工作，UNSUPPORTED 3→0，但三个 unsupported claim
全部无候选证据，实际走的是 WEAKEN/REMOVE——**SUPPORT 路径（检索已有 Verified Evidence →
Writer 用其重写 → 加正确 citation → 复审转 S/P）在真实模型下从未被检验**，因此只能判
PARTIALLY_SUPPORTED。本阶段通过受控 A/B，在保证 Evidence Pool 相对丰富（≥6 verified
sources）的前提下，让 unsupported claim 自然发生并检验 SUPPORT 路径：

- H1：Claim Grounding 开启后，对「UNSUPPORTED 但池内有相关 Evidence」的 claim，系统能
  完成 retrieve → repair context → SUPPORT 修订 → 正确 citation → 复审 S/P 的全链。
- H2：相比无 Claim Grounding 的 baseline，Unsupported Resolution Rate 提高。
- H3：不以新增幻觉事实/错误数字/未经验证 citation 为代价。

## 13. Failure Cases（重大问题与 Root Cause）

本轮无产品 bug、无 run/stage 失败、无运维事故。登记的非阻断观察：

1. **SUPPORT 转换 0/5 的根因链**（本实验核心发现，非 bug）：
   自然发生的 unsupported claim = 「文献图景」类断言（综述怎么刻画 / 某工作存在）→
   其语义支撑 = S006 综述内容或 CAMEL/MemGPT/AutoGen 等系统内容 → S006 无全文
   （DOI-only 无公开 PDF）；S008 CAMEL **有全文在索引里但 grounding 阶段 0 条证据**
   （researcher 的 chunk 检索选择未覆盖）→ formal 池内只剩词面相邻的 E023/E022/E007
   → matcher 按 ≥2 词面命中返回候选（机制正确）→ Writer 语义自检拒绝强配（纪律正确）
   → WEAKEN → 复审对泛指性存在断言仍判 U（判据严格但自洽）→ U 不收敛。
   **瓶颈既不是 matcher（Case C 的表层），也不是 Writer 服从性（Case B 的表层），
   而是 verified evidence pool 的构成与自然 claim 分布的错配 + reviewer 对弱化存在
   断言的判据。**
2. **pre-treatment fulltext funnel 损耗**：8 promote → 5 有全文（2 自动 + 2 promote
   附带 + 1 下载）→ 4 无全文。失败项候选元数据无 arxivId → manual fallback 不可用
   （M9.7.5 同类损耗，产品能力边界）。
3. **预注册 regex 假阳性**：C010「Autonomous chemical research with large language
   models」按关键词集保守通过（与 M9.7.5 C006 HuggingGPT 被排除同象，方向相反）——
   按预注册纪律不做事后剔除，占一个 promote 名额，对主链无影响。
4. **偶发测试 flake**：首轮 backend 全量测试 2 failed（retrieval performance 冒烟在
   并行负载下），零改动复跑 1685 全过——与 main 无关，如实记录。

## 14. Limitations

1. 单项目单次 run × 两臂：所有跨臂比较（score/style/U 计数）n=1，只能作方向性观察；
   本报告的核心结论（SUPPORT 转换 0）建立在臂内 5 条 Type-1 的逐条 trace 上，不依赖
   跨臂计数。
2. 指标口径：指纹断链使「消失=resolved」不成立，语义归宿靠人工逐条核对（已完成全部
   5+3 条）；不同评估者对弱化形态是否算「已处理」可有不同口径，本报告从严（仍 U 即
   未解决）。
3. A 臂的 Type-1 候选是 post-hoc 计算（用 main dist 的产品函数、同 formal 池），非
   14cdcf2 运行时产物——口径与 B 同源，但 A 的 Writer 从未见过这些候选（这正是
   baseline 语义）。
4. binding rate 两臂差异大（A 88.2% vs B 62.9%）——fact reviewer 的 evidenceId 输出
   习惯是 run 间随机行为，非 treatment 效应；该观测噪音限制 binding rate 作为跨臂
   指标的使用。
5. 「自然 Type-1」的分布由 research idea 主题塑造（任务书 §6 的要求），推广到其他
   主题需再验证——「文献图景类 claim 是 unsupported 主体」这一发现在综述型任务里
   可能结构性成立，在实验型论文里未必。

## 15. Next Decision

1. **Claim Grounding 的 SUPPORT 路径按现有证据关闭迭代**：机制各环节（检索/派发/纪律/
   无害性）已被两轮真实实验验证，收益端在自然 claim 分布下为 0，继续调 matcher 参数
   （阈值/Top-K/同义桥接）不解决池子缺证据的根本问题。不建议 M9.7 内再做第三轮。
2. **真正的瓶颈有两个候选方向，属下一里程碑决策**：
   a. **Claim-surface-targeted Evidence Supply**：researcher 的证据提议目前以「检索相关
      chunk」驱动，与写作自然产生的 claim 分布脱节。若要 SUPPORT 路径有意义，需要
      evidence.ground 阶段对「综述性/比较性论断的支撑面」（如 S006 的模块刻画、S008
      CAMEL 的机制描述）定向提案——这是 Evidence Supply 的延伸，不是 Claim Grounding
      的修补。
   b. **弱化终态的语义收口**：WEAKEN 后的泛指性存在断言仍被判 U，U 永不归零（本实验
      两臂三轮 gate 全因 unsupported_critical FAIL）。产品需要定义「泛指性提及」的
      合法形态（reviewer 判据或 gate 口径），否则 WEAKEN 无法终结迭代——这与 M9.7.6
      smoke 的 U 3→0 依赖删除而非弱化的观察一致。
3. M9.7 其余部分（duplicate-id 修复、reviewer repair、citation grounding、evidence
   supply）均已两轮以上真实验证且本轮无回归，建议 M9.7 收口。
