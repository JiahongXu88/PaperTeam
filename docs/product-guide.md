# 产品指南（Product Guide）

> 面向使用者：工作台长什么样、两条产品路径怎么走、哪些地方会停下来等你。
> 技术细节见 [ARCHITECTURE.md](ARCHITECTURE.md)；返修链路深入版见
> [existing-paper-revision.md](existing-paper-revision.md)。

## 1. 两条产品路径

新建项目页（「你想做什么？」）只有两个顶层选择：

- **创建新论文** —— 内部再选论文类型：
  - **研究论文**：输入研究想法 → 调研 → 证据核验 → **可行性评估** → 大纲
    （确认）→ 分节写作 → 引用核验 → 审稿 → 修订 → 质量门禁 → Draft/Final PDF。
  - **综述论文**：只输入主题 → 研究计划（确认）→ 文献检索与遴选（确认）→
    全文准备 → 综述矩阵（确认）→ 跨论文综合 → 综述大纲（确认）→ 综述写作 →
    审阅 → 修订 → 质量门禁 → 综述 PDF。
- **修改已有论文** —— 上传论文 PDF 或 LaTeX 工程压缩包：
  - PDF 可先做**快速 Review**（只读：引用核验 + 分章节审阅 + 可导出报告）；
  - 两者都可进入**系统性改进**：审稿基线 → 录入外部修改意见 → 定向证据补充
    → 修订计划（确认）→ 受限修订 → 校验 → Draft/Final。详见
    [existing-paper-revision.md](existing-paper-revision.md)。

后端按 documentType 派生内部 workflow（综述类 → topic_survey，其余 →
idea_to_paper）；用户不需要知道内部 workflow 名。

## 2. 研究论文的实验数据边界（重要）

PaperTeam **不会为研究论文编造实验结果**：

- 可行性评估（`research.feasibility` / `assessment.target`）给出 HIGH / MEDIUM /
  LOW / INSUFFICIENT 档位；目标达不到时如实说明并建议调整。
- 需要真实实验时，输出 **requiredExperiments 实验清单**：目的、数据集、基线、
  指标、消融与对照、预期产物——然后停下等你确认（HITL）。
- Quality Gate 的可行性规则阻止 LOW / INSUFFICIENT 论文冻结 Final，除非你
  知情接受；Draft 仍可产出（计划、相关工作、方法与实验设计本身不需要数据）。
- 综述论文不适用此门禁（不需要实验数据即可闭环）。

## 3. 工作台结构

- **项目列表页**：继续工作 / 最近项目、新建项目、导入入口卡。
- **项目内标签页**：概览 · 论文产出 · PDF 与结构 · 文献发现（检索 → 候选 →
  入库）· 文献库 · 证据 · 引用核验 · 学术图表 · 目标投稿 · Review（仅已有
  论文）· 工作流。
- **设置 → 模型设置**：Provider / Model / API Key / 测试连接 / 按角色独立
  配置 / 自定义 Provider（见 [model-configuration.md](model-configuration.md)）。
- **Skills**：受控学术 Skill 目录（仓库内审计 seed，无任意 URL 安装）。

## 4. 等你确认的节点（HITL）

任务在关键节点暂停（不继续消耗模型调用），确认后继续；决策随 checkpoint
持久化，浏览器刷新、后端重启都能恢复。常见节点：可行性确认 / 研究计划 /
文献遴选 / 综述矩阵 / 大纲 / 改进计划 / 证据供给 / 修订不收敛或超限（接受
当前稿 / 再修一轮 / 取消）/ 修订复核 / 语言润色。

工作流页会实时显示：阶段时间线（中文阶段名 + 状态）、SSE 同步状态、任务
取消、完成后每阶段耗时。终态有五类产品语义：质量验收通过 / 返修任务完成 /
质量未达标（Draft 可用）/ 自动修订已达收敛上限 / 需要作者裁决——后三类是
**诚实终态**（amber），不是系统崩溃。

## 5. 证据与引用（为什么你的稿子可信）

- **检索 ≠ 入库**：检索结果默认零持久化，显式入库（五种方式）才进文献库。
- **Source ≠ Evidence**：文献里的原文要成为可引用证据，需通过三段核验
  （逐字引文 / 权威元数据 / 语义判定）；只有 verified 证据能进写作上下文。
  详见 [evidence-and-citations.md](evidence-and-citations.md)。
- 引用双层核验：Layer 1 真实性（Crossref / OpenAlex / arXiv；NOT_FOUND ≠
  捏造 ≠ 检索失败）；Layer 2 论断-引用语义一致性（可按 run 关闭）。

## 6. 学术图表（真实数据 → 矢量 PDF → 受控插入）

「学术图表」标签页把你的实验数据变成可插入手稿的矢量图，全程零模型编造：

- **数据必须来自项目内已解析的数据集**（文献库上传的 CSV / XLSX / JSON，
  或 PDF 解析出的表格块）：每张图都锚定 `sourceId + blockId + datasetHash`，
  数据与来源不一致会被拒绝；手动数据需显式标注（manual origin）。
- **数据图**（折线 / 柱状 / 分组柱状 / 散点）由 pgfplots 确定性渲染，
  **方法图**（流水线 / 双列对比）由 TikZ 模板确定性布局，产出独立编译的
  矢量 PDF；同一 spec 恒得同一张图（figId = specHash 派生）。
- **题注真实性守卫**：caption 里的定量声明（数值 / 差值 / 百分比）会被
  确定性核对是否被数据支撑——"提升 5 个百分点"而数据只有 1.3 的差会被
  拦截；无法可靠校验的声明（全称量词 / 计数 / 单位换算）标记
  UNVERIFIED，需你显式确认后才会插入。
- **受控插入**：新论文可按大纲章节追加（自动分配 label + 可选正文引用句，
  模板自动补 graphicx）；已有论文只允许**替换既有图**（label 与位置不变，
  正文 ef 全部继续解析）——图表动作不会成为绕过修订安全边界的后门。
  插入后到「论文产出」发起构建即可得到含图 PDF。

## 7. 修订安全与版本

- Writer 的修订是**受限范围补丁**：事实 / 引用 / 证据保持守卫用代码拒绝
  未授权的数值改动、结论升级、引用丢失；越界改动会被检出并回滚。
- 论文产出页提供不可变版本链：历史（修订号 / 来源 / 门禁结论）、两修订
  确定性比较、恢复历史版本（= 创建新修订，历史永不删除）。
- **Draft / Final 语义**：Build Gate（真实 LaTeX 编译）通过即冻结 Draft；
  Final 要求双 Gate 通过且与当前修订对齐。实验事实被无依据篡改时会阻止
  Draft 产出。

## 8. 限制（诚实清单）

- 视觉评审以确定性检查为主（caption 缺失 / 引用解析 / 表-文数字一致性）；
  图像内容理解依赖 vision 模型配置，未配置时如实降级（不伪造通过）。
- PDF 重建是文本级：重建稿不含原图 / 原版式，公式以转义文本呈现。
- 图表生成覆盖四类数据图与两类方法图模板（不是任意图形语言）；任意格式
  的实验 ZIP 包自动识别不在当前能力内。
- 单机单用户：无鉴权 / 多租户；系统管理后台未实现（Docker 部署可用）。
- Windows 下 LaTeX 编译超时只终止 shell 进程（已知遗留）。
- 项目 / run 列表无分页；EvidenceStore 为 JSONL 全量读写（几十个修订 /
  数百条 Evidence 规模内验证）。
- 学术评分是启发式信号，不是通用投稿预测器；80 分线未做全量校准
  （见研究报告 M11_4_QUALITY_GATE_BENCHMARK）。
